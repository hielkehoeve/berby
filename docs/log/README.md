# Berby build log

Berby is being built in a conversation between its creator and Claude (Anthropic's AI assistant, running in Claude Code). This folder is the public journal of that conversation: one file per iteration, so other people can follow how the game took shape, which questions were asked, what was decided and why.

## Convention

- One file per iteration: `NNN-short-title.md`, numbered in order. An iteration is one round of work that moves the project forward (a design pass, a build phase, a QA round, …).
- Each file has the date, the goal, the conversation (the creator's messages quoted, Claude's answers and decisions summarized), the artifacts that came out of it (files, decisions, open questions) and the status at the end.
- Claude writes the log at the end of each iteration and updates it if the iteration continues.

## Privacy

The logs never contain personal or secret data: no email addresses, API keys, tokens, passwords, or absolute paths from the creator's machine. File paths are relative to the repository root. If you spot something that should not be here, open an issue.
